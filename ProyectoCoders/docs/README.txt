Simulación de un Entorno de
Desarrollo

Eres parte de un equipo de desarrollo que está iniciando un nuevo proyecto. Tu tarea es
configurar la estructura de carpetas y archivos necesaria para organizar correctamente los
recursos del proyecto.

Objetivos:
• Aplicar buenas prácticas en la organización de archivos y carpetas.
• Usar atajos de teclado y comandos del sistema operativo para navegar y gestionar
archivos.
• Entender la importancia de una estructura organizada para el desarrollo de
software.
